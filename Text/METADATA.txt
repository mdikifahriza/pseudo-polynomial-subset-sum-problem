ABSTRACT
--------------------------------------------------------------------------------

The Subset Sum Problem (SSP) is a foundational NP-complete problem with
applications in cryptanalysis, integer programming, and combinatorial
optimization. Practical exact solvers face three recurring bottlenecks:
symmetric Meet-in-the-Middle (MITM) requires O(2^(N/2)) memory and causes
severe CPU cache pressure as N grows; classical dynamic programming (DP)
requires O(T) memory and therefore becomes impractical for trillion-scale
targets; and extracting many distinct witnesses from a branch-and-bound
tree can require expensive re-traversal.

This paper documents Dumb SSP Solver, a native C++20 exact solver that
combines four concrete engineering mechanisms: (1) an asymmetric
tail-table of the m numerically smallest active elements (m = N-1 for
N <= 20, otherwise m starts at 20 and is bounded by memory), yielding a
16.00 MB table at the default m=20 and pruning the last m recursion
levels via a single sorted-table binary search per leaf; (2) a 64-bit
word-parallel bitset DP restricted to small effective targets
(T <= 1.5 * 10^7) and single-witness queries (FindOne/DecisionOnly);
(3) a bounded-degree Zero-Sum Swap Extractor that harvests additional
witnesses by exchanging up to p <= 4 elements on each side of a seed
solution with fixed-degree polynomial complexity
O(k^4 log k + (N-k)^4 log k); and (4) an independent, isolated
black-box verifier (L7) that re-checks index bounds, element uniqueness,
and exact sum equality outside the search engine.

All reported timings are derived from a reproducible single-threaded
self-test benchmark covering instance sizes N=5 to N=100 with
trillion-scale targets. The complete benchmark data are archived in
benchmark.txt and can be independently inspected using dumbsspCli.exe.
